# Punchclock

A very simple time tracking app inspired by tools like Jibble. Single HTML file, no build step, no backend.

## Features

* Add and remove team members
* Clock in, clock out, and take breaks
* Live status board (working, on break, clocked out)
* Hours worked today per member and for the whole team
* Timesheet with filters by member and date
* Export timesheet to CSV
* Data saved in your browser (localStorage)

## Run it

Open `index.html` in any browser. That's it.

To host it for free, enable **GitHub Pages** in the repo settings (Settings → Pages → Deploy from branch → `main` / root).
